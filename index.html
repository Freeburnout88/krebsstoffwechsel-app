Installierbare PWA · Nur Information, kein Therapieersatz

PWA-Manifest ist aktiv (manifest.webmanifest / manifest.json).
Damit PWABuilder die App findet: GitHub Pages muss an sein und du musst die github.io-URL verwenden – nicht github.com.

GitHub Pages einschalten (wichtig!)

  1. Settings → Pages
  2. Source: Deploy from a branch
  3. Branch: main / Ordner /(root) → Save
  4. 1–2 Minuten warten

Dann öffnen:
https://freeburnout88.github.io/krebsstoffwechsel-app/

APK mit PWABuilder

  1. pwabuilder.com öffnen
  2. URL eingeben: https://freeburnout88.github.io/krebsstoffwechsel-app/
  3. Start → Package → Android → APK herunterladen
