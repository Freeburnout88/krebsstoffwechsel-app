Krebsstoffwechsel-App

Installierbare PWA · Nur Information, kein Therapieersatz

Repository ist vorbereitet. Für die Voll-App die Datei Krebsstoffwechsel-Komplett.html einmalig hier hochladen (siehe unten), dann GitHub Pages aktivieren.

1. Voll-App hochladen (einmalig, ca. 1 Min.)

  1. Datei Krebsstoffwechsel-Komplett.html aus dem Download-ZIP bereithalten
  2. Auf GitHub: Repo öffnen → Add file → Upload files
  3. HTML-Datei ablegen → Commit

Upload öffnen

2. GitHub Pages einschalten

  1. Settings → Pages
  2. Source: Deploy from a branch
  3. Branch: main / folder / (root) → Save

Danach erreichbar unter:
https://freeburnout88.github.io/krebsstoffwechsel-app/

Pages-Einstellungen

3. Auf dem Handy installieren

  1. Pages-URL in Chrome (Android) oder Safari (iPhone) öffnen
  2. Android: Menü → App installieren
  3. iPhone: Teilen → Zum Home-Bildschirm
Bis die Komplett-HTML hochgeladen ist, nutze die lokale Datei aus dem ZIP (doppelklicken). Alle Funktionen sind offline verfügbar.
